# Lessons — feat-jev-decision-kernel

- Wait for a prd release with `grep -q '^Deployed'` or the script exiting (`pgrep -f '[r]elease.sh <id>'`; without the brackets pgrep matches the remote shell running the check, so a failed release polls forever). A loose `healthy` pattern made a finished release look stuck for 30 minutes, and a loose `rror` pattern matched build output and reported a release that was still building.
- Markdown under `docs/` must pair English and Chinese; keep worktree lessons under top-level `tasks/<worktree>/`.
- prd has no pytest; real acceptance runs use the standard-library `unittest`.
- A marker that names line numbers works for the model but not for a person: the terminal card shows no line numbers. Check model-visible text in the browser card as a user would, not only in the session log.
- In the browser, tool cards sit under "Took Ns" → "Ran commands and read files" → the card itself; terminal lines render as `div`s, so locate text with a tree walker, not `pre`.
- The worktree guard rejects compound shell commands that export variables or start interpreters with computed input; put them in a scratchpad script and run `bash script`.
- `gh pr create` fails with this token (GraphQL permission); create pull requests through `gh api repos/<owner>/<repo>/pulls`.
- Run `bash -n` on every browser acceptance script before a prd run, and re-read a scratchpad file after a guarded edit: a fix the worktree guard refused left a syntax error that stopped two prd runs right after the first message.
- In a shell `case` pattern, quote any part containing spaces (`*"moved into the current step"*`); an unquoted space ends the pattern.
- prd went down on 2026-10-08 because the shared disk filled: every release left a 2.5 GB directory and a 5 GB image. `release.sh` now refuses to build below 20 GB free and prunes to the newest three releases; check `df -h /` first whenever the service shows `226/NAMESPACE`.
- A relay's response `model` field echoes the requested alias, so it proves nothing; the upstream channel is in LiteLLM's `x-litellm-model-id` header, and `usage.prompt_tokens` differences for a fixed prompt may indicate tokenizer or hidden-prompt differences, but do not certify model identity.
- When the root filesystem is full, growpart cannot create its default /tmp directory. Check /run is tmpfs with space, then use TMPDIR=/run for dry-run and growth; verify the partition start stays unchanged, grow ext4 online, and check writes as the service user.
- Preserve report.html as the user-designated promotional artifact. Track implementation gaps and measured acceptance in engineering records; improve the product toward the stated goals instead of silently reducing the promotional claims.
- Every claimed feature needs complete implementation and a real end-to-end acceptance run with actual external models and product execution. Unit coverage and keyless SDK replay supplement this evidence; neither alone marks a feature complete. Retain positive and negative cases, exact build/config, and persisted user-visible results.
- A Host-only build can leave old Web client assets. Rebuild the client and verify its version together with source and bundled artifact hashes before browser acceptance. Isolate DSH_HOME, DSH_AGENTS_HOME and documentsDirectory; fixtures belong in documents/deepseek-harness/default-workspace.
- A model-authored create_goal objective can replace the initial task-frame message and clear its items. Preserve applicable human requirements independently before claiming execution constraints; include initial-message, capacity, read-only-tool and delegation negative cases.
- Check plugin-only disposal separately from Agent cancellation. An in-flight judge must not record or apply a result after its owner is removed; canceled callers do not resume native tools, while removing only the review leaves native execution available. Reject an active dependency on taskFrame mode off at load.
