# @deepseek-ai/dsh-experimental-client-ui-system3

[English](README.md) | 中文

## 概述

这个可选 Client 插件展示 System3 对每条输入做了什么。紧凑的 Conversation 区块分别列出提交反馈、System3 建议、采用与实际响应的模型、Skill 注入、调度模式、委派阶段和委派运行的进度。每个轮次标题写明由谁处理该轮次的输入，以及判断是在本机还是云端完成。Web 与桌面通过产品 profile 加载该插件。

<a id="configuration"></a>
## 配置

将这个 Host 发现入口与 System3、原生 Conversation Client 插件一起加载。本包没有部署设置。产品 profile 负责 Jev、生成模型路由和数据权限。界面文案由类型化的中英文字典管理。

<a id="behavior"></a>
## 行为

产品标题为 APUS Reflex Harness；`system3` 插件与 locale 标识保持不变。

原生轮次标题（`conversation.chat.turnHead`）中的路由说明同时标出已记录的入口决策在哪里完成：本机（提示说明判断内容没有发往判断服务）或云端；执行依据中以“判断位置”同样列出。轮次标题显示 Reflex 判断时，以该判断代替路由说明。

更早的轮次依据投影的 `history` 保留各自的路由说明。运行中的轮次把任务交给子 agent 时，输入框 `conversation.input.right` 位置的条目在模型选择器旁写明委派对象，模型选择器仍显示负责协调的模型。区块订阅原生 Session 和投影。本地提交在路由结束前显示。执行状态独立于历史入口建议，跟随实时 Session；历史回放后仍可查看决策详情。轮次结束不代表交付物已通过验证。监督送达未确认时，文案说明缺少回执且未重复发送，不声称 Reflex 没有作出判断。固定模型操作调用原生重置 API，并等待持久模式改变；调用失败保留当前显示模式。被寻址的子智能体不能修改根会话模型选择。委派运行接受运行中输入时，区块提供补充说明表单，通过原生 `subagents.steerByParent` Remote 发送用户文本；发送被拒绝时保留文本并显示提示，Host 记录后已接受的文本显示在运行下方。

当前回合标题与可见状态栏在主模型回答前展示已记录的 Reflex 输入类别或选中 Skill 及准备耗时。判断、Skill 加载与任务完成分别表达；超时或无有效判断显示回退状态，不伪造结果。提交新输入后隐藏上一条判断；回合标题只显示属于该回合的判断。

<a id="reflex-configuration"></a>

## Reflex 配置

本实验性客户端自行挂载 Reflex 的类型化 Remote；通用 API Remotes 不依赖该实验模块。客户端卸载时先撤销界面，再撤销 Remote。

页面沿用“通用设置”的行布局：标题与副标题之后是“启用 Reflex 决策”总开关行，再是“决策服务”“决策前置”“记忆”三个带标题的模块；模块之间的间距大于行间距，模块本身不加边框。总开关独立于暂存的连接表单，立即写入 `jev` 条目的 `enabled` 字段，唯一的状态行说明新请求按所选接入方式做判断，或回答直接由主模型生成；关闭期间所有请求按原生流程执行，不调用决策服务，各模块标题追加“已暂停 · 随总开关”，模块内容变暗、控件不可用；写入被拒绝时页面会提示。“决策服务”包含“接入方式”行，其菜单提供“APUS Reflex 限时免费端点”、“自定义参数”和“本机”，说明随所选方式变化，其下只渲染所选方式的内容。预置与自定义方式显示各自字段、一行保存行（左侧为生效说明或保存失败原因，右侧为“保存”），最后是带测试按钮的“连接状态”行。“本机”渲染 root scope 的 `settings.reflex.local`，由本机决策引擎插件填充，未注册时提示前往插件页开启；它没有“保存”，因为选择它即通过 `ctx.reflexLocalMode.choose()` 提交，其操作也立即生效，连接状态由其卡片自行说明。`jev.defaultProviderId` 指向非内置 provider 时，或该字段缺省而本机引擎报告已选择本机接入方式时，页面显示“本机”，因此停用本机判断或删除模型都不会改变接入方式；选择未能保存时在接入方式行下提示。选择预置或自定义方式时，把 Jev 内置 provider id `system-one` 暂存，随页面常规保存写入；它与缺省字段路由相同，并结束本机选择。预置模式暂存公开地址、模型和专用 `APUS_REFLEX_TRIAL_API_KEY` 引用，隐藏连接与密钥字段。Host 必须单独配置该凭据；客户端不包含共享密钥，也不执行限期或配额控制。自定义模式显示地址、模型、决策强度、超时与凭据引用。“决策前置”在 Host 提供 `system3` 设置命名空间时显示一个开关，立即写入 System3 条目的 `frontLoadedDecisions` 字段（缺省即开启）；其下以紧凑只读行列出输入判断与 Skill 选择、用户入口路由：运行时为“已启用”，被开关暂停时为“已暂停 · 随决策前置”，本构建未安装时不显示该行；没有任何一项运行时这些行变暗，开关保存成功后重新读取。“记忆”承载 root scope 的 `settings.reflex.item` 列表，供独立挂载的控件使用，例如 Continuum 伴生插件与 Host 命名空间可用时的记忆开关；没有任何行渲染时整个模块隐藏，总开关关闭时不接受输入。Web/Electron 共享客户端将“设置 → Reflex 配置”注册为独立页面。配置通过 ConfigForms/Credentials 保存，未保存的测试通过鉴权后的 `reflex` Remote 执行。凭据原文不会回读或写入浏览器存储；部署环境提供的密钥保持只读。

切换模式使正在进行的探测失效，并清空未保存的密钥文本。控制器加载期间保留自定义连接草稿，自定义参数不接受试用凭据引用，页面也不会清除试用凭据。保存只持久化当前连接；重新打开时，已保存的 `defaultProviderId` 表示本机方式，否则根据地址、模型和凭据引用识别预置模式。丢弃操作恢复已保存连接；切换到“本机”时丢弃暂存修改但保留所选方式，关闭页面时回到已保存的方式。已有自定义配置打开后保持选中；尚未配置时默认呈现需要保存的预置草稿。

保存新 API Key 前，页面先检查凭据引用；若引用已配置，则拒绝覆盖，配置与密钥均不修改。轮换密钥必须使用新的专用引用名。

草稿测试通过不会改变已存配置状态，保存成功后才刷新为已配置。运行状态查询失败单独显示，不把已成功保存误报为失败。

连接结果与能力状态分别呈现。修改草稿后旧检测结果失效，旧草稿的延迟响应会被丢弃。即使已有旧密钥，凭据写入被拒绝也会显示保存失败。能力标签来自实际模块与启用状态，不从连接成功推断执行已验收。

目标相关性监督单独报告 `semanticSupervision.enabled` 状态。只有监督模块已安装、处于 active 模式、显式配置语义证据且当前工作区数据策略允许时才启用。该子能力未启用时，操作指纹监督仍可启用；两种状态均不代表已验证执行效果。

连接配置与密钥组合保存无法确认凭据写入时，页面仅在本轮已确认版本上恢复配置字段。较新的并发修改不会被覆盖，此时显示部分保存提示而非普通失败。草稿继续保留，重新打开页面读取已接受设置。配置与凭据属于独立服务，断连时不承诺跨服务原子性。

<a id="model-experience"></a>

## 模型体验

无，因为这个浏览器插件不新增模型可见输入。它呈现 System3 提供的 Client 安全事实，仅在用户操作时调用现有 Session controller。

#### KV Cache 影响

无直接影响；后续请求变化由原生模型选择负责。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- 建议不等于执行。只有精确对应的指令消息提交后，Skill 才显示为已注入。区块不显示虚构百分比、定时成功、私有提示正文或 provider 概率。用户固定模型后，之前的自动决策仍属于历史记录。原生工具、交付物、错误、取消、目标和专家会话继续由各自现有 UI 负责。
