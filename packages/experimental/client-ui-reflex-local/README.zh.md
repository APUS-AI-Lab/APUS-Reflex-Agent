# @deepseek-ai/dsh-experimental-client-ui-reflex-local

[English](README.md) | 中文

## 概述

此可选浏览器插件在“设置 → Reflex 配置”的“本机”接入方式中以及 Bundle 页面渲染本机决策引擎卡片，开启 Bundle 时提供一键下载，在输入框上方显示后台准备状态，并在本机判断启用时以带撤销操作的提示告知。所有界面共享一个 Host 就绪订阅。

<a id="use-this-package"></a>
## 使用此包

在插件管理页启用[本机决策引擎 Bundle](../reflex-local-bundle/README.zh.md)。这台 Mac 能运行引擎且尚未下载模型时，弹窗提供带下载大小的“下载并启用”或“稍后”；可用空间不足时改为打开详情。卡片是 Reflex 页面上唯一带边框的分组：标题行是模型下拉框，带一个状态、一个主操作和“更多操作”菜单，其下是一行事实说明，下载期间还有进度条。下拉框按模型规格分组列出所有可选的模型与量化档，写明下载大小和内存需求，并标注“推荐”“实验性”“已下载”“使用中”；所有选项都可选，这台 Mac 可能运行不了的选项在名称后用括号写明不足之处（所需内存与这台 Mac 的内存，或磁盘空间不足）。选择选项只改变卡片描述的模型；卡片在暂停和失败之后仍描述该模型及执行过操作的模型；删除模型后以及重新打开时，卡片描述正在使用的模型，没有时描述 Host 准备状态所指的模型，再没有时描述推荐项，仍没有时描述最小的选项。所描述模型的状态为使用中、未启用、已下载、未下载、准备中（带百分比）、已暂停、正在检查、自检中、故障或 Reflex 已关闭。主操作为带下载大小的“下载并启用”（已有其他模型在用时为“下载并切换”）；下载中为“暂停”；已暂停或部分下载的文件为“继续下载”；其他已下载模型为“使用”（自检较慢时为“仍要使用”），没有通过自检的已下载文件为“校验并启用”（已有其他模型在用时为“校验并切换”）；使用中为“停用”；停用后为“启用”（较慢的 Mac 上为“仍要启用”）；失败后为“重试”。“更多操作”包含“删除此模型”（仅在删除正在使用且本机判断已开启的模型时先确认）、“取消下载”（删除已下载部分前先确认）和“下载来源”。对正在使用的模型，事实行说明推理进程：运行中及约占内存，自检后另写每次判断的秒数；正在加载（开启本机判断时先启动推理进程，期间也显示）；已停止；或“失败：”加 Host 给出的原因。另一模型在后台准备时（任何阶段），当前模型继续判断，第二行写明它，卡片未描述正在准备的模型时也写明后者，本机判断开启时“更多操作”提供“停用当前模型”；另一模型正在下载时选择新模型，会先询问是否暂停该下载。无法运行引擎的设备显示原因，不提供操作。可用空间放不下所描述的模型时，禁用的主按钮写明需要与可用的空间。内存可能不足的模型，事实行同样附上括号提醒；点击普通主操作时先弹出只有“知道了”的提示，写明所需内存与这台 Mac 的内存，点“知道了”或关闭提示都会继续，以 `allowUnfit` 调用 `prepare`；Host 以 `reflexLocal/unfit` 拒绝时先显示同一提示再重试。下载大小用十进制 GB 并保留一位小数；内存档位按 Mac 的标称方式用二进制 GB 显示为整数。卡片从 Jev 设置表单实时跟随总开关（没有该表单时才用 Host 快照中的值）。Reflex 决策总开关关闭时，下拉框、“更多操作”以及除“暂停”外的所有主操作都不可用，正在使用的模型状态显示为“Reflex 已关闭”。下载进行中、已暂停或正在检查时，以及较慢的 Mac 等待决定时，输入框上方的标签显示当前状态；其菜单按状态提供“暂停”或“继续下载”、“取消”（与卡片的“取消下载”使用同一确认）、“仍要启用”与“查看详情”。“暂不启用”在页面重新加载前隐藏较慢 Mac 的标签，不改变 Host 状态。自检自动启用本机判断时，提示条显示“判断已在本机进行”并提供“撤销”，撤销即停用；后台模型通过自检并替换当前模型时，提示条写明新模型并提供“撤销”，撤销即重新选择原模型。当时没有打开页面的话，提示条在下次加载时显示。插件还提供 `ctx.reflexLocalMode`：Host 持久化的本机接入方式选择及 `chooseLocal()`，Reflex 页面据此保持“本机”。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>维护者信息 — 点击展开</summary>

插件挂载生成的 `reflexLocal` Remote 并注册五个条目：`settings.reflex.local`，以 Bundle 名为键的 `plugins.bundle.config` 与 `plugins.bundle.activation`，顺序为 6、在上述状态之外不渲染任何内容的 `conversation.input.dock` 标签，以及生命周期长于插件页面、同时报告标签命令失败的 `shell.overlay` 提示。一个就绪镜像经网关流自动重连，断线期间保留最后的快照。卡片中让模型变为正在使用的操作都调用 `prepare({ variant, downloadSource? })`，Host 将其视为对该档的 `select()`。Host 把自动启用记为 `unacknowledgedAutoEnableAt`、把后台切换记为 `unacknowledgedSwitch` 并跨重启保留，因此自检期间关闭的页面之后仍会收到提示：插件对每个标记值只显示一次，并在提示关闭时调用 `acknowledge()` 或 `acknowledgeSwitch()`，因此提示可见期间关闭的页面下次会再次提示；“撤销”调用 `disable()`（同时清除两个标记）或 `select(from)`。命令失败在卡片或弹窗内就地显示。就绪来自一个 Host 订阅且提示只有一个拥有者，因此不发布运行时不变量伴随模块。

</details>

<a id="model-experience"></a>
## 模型体验

无，因为卡片、弹窗与提示只控制准备与启用；Jev 判断只经由既有消费方影响模型。

#### KV 缓存影响

没有直接影响；插件不向任何请求前缀添加内容。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 体验设计中的邀请卡与判断来源徽标尚未实现。下载可从“设置 → Reflex 配置”或 Bundle 页面开始；“查看详情”与启用引导打开 Bundle 页面，因为没有可打开指定设置分区的服务。
- 进度使用原生 `progress` 元素，因为基础组件中没有进度组件。
