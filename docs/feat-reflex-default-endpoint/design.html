Reflex 接入与即时判断体验

目标：每次普通文本输入后尽快显示真实 Reflex 判断，随后由主模型继续。约一秒是待验收的体验目标，不是已证实的服务保证。用户已明确要求两种接入方式及直接展示判断结果。

接入界面

仅保留「APUS Reflex 限时免费端点」「自定义参数」两个选项，服务协议显示 Reflex。免费模式隐藏地址、模型与密钥字段；自定义模式可编辑自己的参数。后端协议标识保持兼容。默认 endpoint 与 model 是公开配置，凭据仅存本机 managed credentials，安装包不包含共享 Key。

预置凭据引用 APUS_REFLEX_TRIAL_API_KEY，与自定义引用隔离；切换模式不向其他地址携带预置密钥。未获凭据的新安装不能宣称免费服务已激活。公开服务的有效期、配额及凭据发放尚需服务端实现。

请求与显示链路

用户提交 → 立即显示已接收 → Reflex 有限类别判断（候选较小时同时选 Skill） → 显示真实判断及耗时 → 主模型执行与正文回复

Jev 返回分类和概率，不生成自由文本正文。界面由语言字典将分类映射成中性描述，选 Skill 和注入 Skill 依据不同事件显示。没有命中 Skill、大目录等情况不静默丢弃候选；可仅做输入类别判断，Skill 发现交给原生主模型。

约一秒为目标，当前真实服务在一秒强制期限下多次超时；改用可配置三秒总准备上限，超时后原生聊天继续；超时不显示伪造判断。所有分类失败、网络失败、超时保留。输入超过预算时保留完整原文，不截断后冒充已理解全部输入。

显示规则

回答上方使用紧凑状态条，含 Reflex、真实判断类别或 Skill 名称、本次实测耗时。判断中原位更新；详细依据折叠。示例「Reflex · 日常交流 · 480 毫秒」仅为版式示例。「建议检索历史记忆」不等于已完成检索，「已选择 Skill」不等于已执行任务。新一轮输入不复用上一轮结果，读屏只播报真实状态变化。

文件与接口

  • client-ui-system3：接入控制器、双语字典、设置界面、即时判断显示及对应 UI/controller 测试。
  • system3：输入判断与 Skill 选择、运行状态投影、Session 事件兼容及真实 Loader 测试。
  • apus-dsh-jev-plugin：独立 Skill 能力状态；不改变 systemone 网络协议。
  • frontend/scripts/generate-system3-patch.mjs：正常桌面加载执行插件；安全模式保持独立。

保存和测试使用现有 settings / credentials / reflex Remote；不将密钥放进浏览器存储或 Session 日志。公开分类为有限枚举，未知值拒绝显示为成功判断。现有 Session 数据必须可继续读取。

验收与速度口径

指标起止点
有效反馈可见时间用户提交 → 本次真实决策在界面完成渲染
决策耗时决策准备开始 → 有效决策完成，独立于网络首字
正文首字用户提交 → 主模型首个非空正文完成渲染，排除 thinking 和固定提示
完成耗时用户提交 → 最终任务结束，并单独报告质量

OFF/ON 同题、同主模型和 thinking 设置，配对交错；保留 Flash 关闭 thinking 对照。报告 P50、P95、1 秒内有效反馈比例、判断正确率及超时率。成功样本的快响应不能代替所有输入的成功覆盖率，3× 尚需足够独立案例支持。

  • 双模式切换、保存重开、丢弃、缺凭据、密钥隔离、已有自定义值保留。
  • 普通对话、记忆请求、资料查找、生成内容、工具操作、不确定输入、无 Skill、大目录、长输入、超时与错误。
