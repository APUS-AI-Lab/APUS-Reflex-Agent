# Windows 规范化路径

[English](path-compatibility.md) | 中文

Windows 原生 CI 已生成安装包，但在 8.3 临时短路径下暴露两处失败：图片写入子进程把未规范化的工作目录交给规范路径检查，PPT CLI 则比较了已规范化的 argv 路径与未经规范化的模块 URL。

## 实现

图片写入前先规范化工作目录，与宿主的工作区解析行为一致。继续拒绝生成图片目录及目标文件的链接逃逸。PPT 入口与模块 URL 均按实际文件路径规范化后比较；导入模块不执行 CLI，直接入口或 npm 链接入口执行 CLI。不改变 API、凭据或持久化格式。

## 文件与验证

修改维护中的图片 writer 与 PPT 编译器输入、所属 README 描述，按需扩展既有干净源码子进程回归。本地运行图片目录约束及 PPT CLI 回归，随后运行完整 Windows 原生桌面测试与安装后验收。源码回归从 Git 索引读取，避免本地生成副本掩盖修复缺失。
