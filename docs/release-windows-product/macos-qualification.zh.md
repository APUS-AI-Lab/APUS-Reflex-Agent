# macOS 已安装包验收

[English](macos-qualification.md) | 中文

## 范围

macOS 辅助脚本在原生 Apple Silicon 或 Intel runner 上验收已收集的 DMG。`--expected-source` 指定完整产品源码 SHA；正常构建默认使用工作流检出的 SHA。再验收显式传入已有产品 SHA，并通过 `--build-run-id` 标明构建任务。报告分别记录 `sourceRevision` 和 `helperSourceRevision`。安装器哈希、已安装运行时架构与源码、应用版本、首页、重启和进程退出必须全部通过，报告才记录成功。

## 镜像处理和诊断

挂载镜像和复制应用各有 600 秒的等待上限，卸载镜像上限为 30 秒。命令记录保留耗时、超时设置、退出状态、终止信号及脱敏后的有界输出。即使挂载命令在报告成功前失败，清理仍检查实际的私有挂载点；已挂载的镜像必须卸载。报告分别保留主失败和清理失败，任一失败均阻止验收成功。

## 验证和限制

定向测试执行真实子进程，验证超时和非零退出诊断，拒绝不一致的源码选择，并区分私有挂载点与邻近路径。原生 macOS CI 提供复制后应用及浏览器证据。预览版未签名；不验收公证及 Gatekeeper 信任。验收不使用提供商凭据，也不执行真实模型 API 任务。
