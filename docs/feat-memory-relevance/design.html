Continuum 覆盖优先 Reflex 批量排序

本附录落实整体架构唯一入口的覆盖优先原则：Reflex 判断相关性并调整阅读顺序，主模型判断使用；所有已授权且通过完整正文预算的候选均保留。本批不添加语义索引或跨会话来源读取。

接口与配置

Jev 现有请求已支持每题独立 noul 概率，单批上限 16。每个候选对应 m0…m15 之一；候选内容仅作为数据，不执行其中指令。state 包含 query 和 bounded candidate id/label/excerpt/lexicalScore；questions 询问每个候选是否可能提供相关事实、约束或部分证据。不将 choice.confidence 解释为候选独立相关概率。

新配置 mode、timeoutMs、maxRequestBytes、privacyPolicy；旧 minConfidence/maxSelections 明确报迁移错误，受控消费者同步迁移。profile 默认 off、2000ms、32768 bytes、local-only。直接函数调用接受已经明确的配置。所有 Jev 传输按 network 路由处理，复用 admitSystem3Routes，以实际 resolve 得到的 providerId 对照 approvedRemoteIds，并要求 workspace 数据类许可；未授权时零网络请求，保留全部 baseline。

resolve 完整保留 providerId/model/effort。按最终 resolved JSON 请求计算 maxRequestBytes；超限保留 baseline，不静默截断用户问题。active 依据 noul 降序稳定排序，仅已评分候选重排；未评分候选保留原位。shadow 记录建议但仍传 baseline；off 和空候选零调用。超过 16 个候选的余项保留并记为未评分。不提供语义过滤阈值。

持久化与取消

continuum/memory-decision 的既有 version:1、selectedIds、baselineIds、outcome、历史 confidence/failure 继续可读；新增 optional evaluation，独立 version:1，含 strategy、完整已提交 Jev request、response、rankedIds、unscoredIds、reason。旧记录不重写；生成兼容性 acknowledgement。新模型输出不写旧单一 confidence 字段。取消传播且不追加迟到 receipt；超时或 provider unknown 保留 bounded baseline。共享上下文读取 ticket 继续在注入前验证，context 按已验证 selectedIds 顺序重建候选。

验收

  1. 一次 HTTP 请求含多题独立 noul；两条互补证据与低概率/未知候选均进入最终主模型请求。
  2. 0/1/16/17 候选，平分稳定、未评分保留、没有候选创造或重复，完整正文预算保持。
  3. off 零请求；shadow 不改变顺序；active 只排序；超时/429/协议错误完整 baseline；缺配置报错。
  4. 默认拒绝出站；providerId 未批准/数据类未批准零网络；完整 resolved spec 正确传输；请求超预算零网络。
  5. 取消前/中/晚响应不提交；dispose quiescence；独立 HTTP 测试监听动态端口，进程/临时目录独立并清理。
  6. v1 历史 receipt 可读，新增 evaluation 原样回放且不调用 Jev；真实 profile source/lib 链路与 keyless snapshot。

工程链路验收不等于模型效果验收。模型概率未校准；后续以固定上下文预算下证据覆盖率、任务成功率、调用次数和延迟检验真实效用。
