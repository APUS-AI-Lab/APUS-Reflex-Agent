异步状态与 Session 隔离补充

独立终审发现：等待 Jev 期间新要求可以更新任务卡，旧判断不能代替新要求的核验；任务卡的旧判断也不能覆盖期间创建或编辑后的 Goal。修复以最新已提交状态为依据，使用确定性屏障覆盖竞态。拒绝额度归属 Session 和 GoalId，独立 fork 不共享额度；仍保留进程内存与配置上限语义。源场景与双 SDK 验收继续验证稳定路径，新增竞态由 owning 行为测试覆盖。
