定位

即时决策融合：反射层 + 推理层

人碰到烫的东西会先缩手、再思考。今天的 agent 却把“该不该换个模型”“这句是不是新要求”“现在能不能插话”这些本该条件反射的判断，全部交给大模型慢慢想，或者干脆不判断。APUS REFLEX Harness 把这些判断抽出来，交给专门做即时决策的 Jev，融合进 harness 的每个关键节点。

REFLEX 反射层Jev 9B · 0.3–1 s
只回答封闭问题（是非、选择、打分），给出概率；拿不准就弃权。判断之后由 harness 直接执行动作：换模型、记要求、插入当前轮、转发 Codex、折叠日志。每一次判断都完整记录，可回放。
推理层DeepSeek Flash / Pro · GPT · Codex
按反射层的选择接手任务，专心推理、写代码、调用工具。用户的要求由任务卡持续提供，中途的补充由反射层及时送达。
Harness 底座DeepSeek Harness
agent loop、会话日志、工具、子 agent、目标与待办。反射层通过公开扩展点接入，不改 agent loop。
核心卖点

融合 Jev 之后，harness 多了什么

01

亚秒级即时决策

每个判断 0.3–1 秒，任务卡和插话在后台进行，不拖慢回答。一次请求可同时问多道题，判断成本远低于让大模型自查。

prd 实测：入口路由 0.3–1 s，插话约 1 s 生效
02

决策与生成分离

小模型负责“判断”，大模型负责“干活”。判断结果不是塞给大模型的一段提示，而是 harness 直接执行的动作。

换模型、插入当前轮、转发 Codex 都是直接动作
03

反射点覆盖完整生命周期

从用户开口、每条新消息、运行中插话、工具输出，到宣布完成之前，每个关键时刻都有对应的反射判断。

5 个反射点已上线，完成前核验即将上线
04

概率可控，拿不准就不动

每个判断带概率和阈值，设有弃权选项。拿不准、超时或出错时回退到原有行为，永远不挡主流程。

只改问法、不调阈值；精确率优先
05

每个反射都能复盘

完整的判断请求与响应写入会话日志，刷新、回放不再调用模型，随时回答“当时为什么这么做”。每次判断前做隐私准入。

判定内核统一记录
06

一套反射层，调度所有模型

DeepSeek 官方 Flash 与 Pro、GPT-5.6 与 GPT-6、外部 Codex agent，统一由反射层按任务调度，变慢的线路自动避开。

简单问题 Flash 约 3 秒，难题交给更强的模型

真实效果

修改前后：都在线上真实跑过

目标运行中，用户补一句“测试文件改名为 check_ledger.py”

以前消息排队到这一轮结束；目标已被标记完成，模型才看到要求，只能事后核对。
现在约 1 秒判为当前任务的要求，插入正在运行的这一轮；模型先改名、再跑测试，最终交付的就是 check_ledger.py。

交给 Codex 后，中途补充要求

以前Codex 跑完才轮到主模型看到补充，Codex 按原来的理解交付。
现在补充同时转给正在运行的 Codex，卡片上显示“已补充（24 秒）”，Codex 交付即符合要求。

说“等一下，先别运行测试，先改名”

以前“打断”这类话不像要求，容易被当成闲聊排队。
现在单独识别“打断当前操作”，留出集 16/16 全对；道别（“今天先到这”）不会被误当成打断。

测试大面积失败，日志又长又重复

以前同一段 diff 和堆栈为每个失败各打印一遍，模型读一大堆重复内容。
现在重复段折成一行，写明“与上文第几行相同，开头是……”；真实失败日志节省 57–65%，展开可逐字节还原。

翻译一句话 vs 推理一道题

以前整个会话固定一个模型，要么慢要么不够强。
现在翻译交给 Flash（约 3 秒），推理题交给更强的模型；每轮开头写明“这次交给谁、为什么”。
为什么做在 harness 层

反射应该长在系统里，而不是写在提示里

比提示词更可靠把“记得核对要求”写进提示，大模型可能忘、可能不照做。反射层在固定时刻必然触发，判断后由系统执行。
比换更强的大模型更便宜让大模型每一步自查，成本和延迟成倍增加。9B 的 Jev 亚秒级完成，一次请求可同时回答多道题。
比规则更懂语义“先别跑全量测试”“等你忙完帮我看邮件”，规则很难区分；反射层按语义判断，并给出概率。
不绑定任何大模型反射层与推理层解耦，DeepSeek、GPT、Codex 可随时替换或组合，反射能力保持不变。

汇报用

30 秒电梯稿

APUS REFLEX Harness 是一个即时决策融合的 agent harness 架构。我们把“该用哪个模型”“这句是不是新要求”“能不能马上插进去”这类判断，从大模型里抽出来，交给 9B 的 Jev 在亚秒级内完成，判断结果直接驱动动作：每条消息 0.3–1 秒选对模型，用户的要求按原话记成任务卡，运行中补一句话约 1 秒生效，连正在跑的 Codex 也能收到。每一次反射都完整记录、可以回放，每次发布都在公网做真实的浏览器验收。下一步是完成前核验，让它在宣布完成之前先自己验收。

3 分钟汇报提纲

  1. 问题：agent 把本该条件反射的判断全交给大模型慢慢想，结果是忘要求、听不进中途的话、委派出去就失控。
  2. 定位：APUS REFLEX Harness，即时决策融合的 harness 架构。反射层（Jev 9B）做亚秒级判断，推理层（大模型）专心干活。
  3. 卖点：亚秒级决策、决策与生成分离、覆盖完整生命周期、拿不准就不动、每个反射可复盘、一套反射层调度所有模型。
  4. 效果：演示目标运行中补一句改名，dock 提示插入当前轮，模型先改名再测试，交付即符合要求。
  5. 证据：126 条标注集、留出集只跑一次、5 个公网浏览器验收场景、验收中发现并修复 6 处体验问题。
  6. 下一步：v0.2 完成前核验；需要的支持是更多真实用户会话，用来扩充标注集。
