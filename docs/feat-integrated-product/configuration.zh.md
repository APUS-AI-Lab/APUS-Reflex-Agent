# 配置模型并完成首个任务

[English](configuration.md) | 中文

桌面客户端默认以普通模型模式启动。先配置你可以访问的服务商，选择工作区并验证一次响应，再运行较大的任务。普通模式不需要 Jev 凭证。生成模型负责对话、推理和工具调用；Reflex/Jev 服务负责结构化决策。两者的地址、模型 ID 和凭证分别配置，不能将 chat-completions 地址直接当作决策服务。

## 配置服务商

1. 打开**设置 → 模型**，按你的服务添加目录中的服务商或自定义服务商。
2. 按服务要求填写 API Key 并选择模型。自定义服务商至少需要唯一 Provider ID、API 协议、Base URL 和一个准确的 Model ID；显示名称可选。Provider ID 以小写字母开头，使用小写字母、数字和连字符。协议须与生成服务一致，如 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages。使用服务商给出的 API 基础地址，不填写网站首页或 Reflex 决策地址；无认证服务不需要虚构密钥。
3. 保存配置，开始新对话时主动选择刚配置的服务商和模型。添加服务商不会自动更改当前选择或全局默认模型；发送前核对模型选择器中的服务商与 Model ID。

使用你自己的服务商账户凭证。APUS 不附带模型订阅或共享 API Key。保存配置或获取模型列表不代表推理可用，下一步的首次响应用于检查真实模型访问。

官方 DeepSeek 适配器使用 Messages 协议，默认地址为 `https://api.deepseek.com/anthropic`。接入 OpenAI 兼容服务时，请添加自定义服务商，按服务支持选择界面中的 **OpenAI Chat Completions** 或 **OpenAI Responses**，再填写相应 Base URL 与模型 ID；只替换官方 DeepSeek 卡片的 Base URL 不会切换协议。

内置服务商的模型列表来自已安装目录（catalog），并不验证当前密钥、远程模型可用性或生成请求。自定义服务商即使成功获取远程模型列表，也仍需真实对话验证。

## 验证任务

选择一个临时文件夹作为工作区，然后新建对话，让所选模型回复一个短句，确认响应出现且没有认证或连接错误。再要求它在该文件夹创建一个小文本文件，并检查结果。审阅请求的访问范围后再批准工具操作。

退出并重新打开应用，确认模型配置仍可使用、对话可以打开。测试任务可能产生模型服务费用。工作区访问与远程模型推理是两回事：模型请求可能向配置的服务发送任务和文件内容。

## 排查配置错误

| 现象 | 检查项 |
| --- | --- |
| 认证失败 | 服务商是否正确、API Key 是否有效、账户权限与额度 |
| 模型不存在 | Model ID 是否准确，以及账户是否有权使用 |
| 连接失败或超时 | Base URL、服务商状态、代理与网络访问 |
| 没有选择模型 | 为对话选择已保存的服务商与模型 |

保留原始错误用于排查，分享之前先去除密钥。凭证使用现有本地凭证存储，位于 `$DSH_HOME/.credentials.yaml`；请保护该目录，不要提交到仓库或作为 Issue 附件。

## 可选的 Reflex 决策服务

打开**设置 → Reflex 配置**。选择 **APUS Reflex 限时免费端点**使用预置服务，或选择**自定义参数**接入自己的服务；服务协议统一为 Reflex。预置模式隐藏地址、模型和密钥字段，需要部署提供凭据，安装包不包含共享 API Key。预置服务不可用时可使用自定义服务。生成模型仍在**设置 → 模型**配置。

| 自定义字段 | 填写内容 |
| --- | --- |
| 服务地址与决策模型 | 决策 API 根地址或 `/v1` 基础地址与真实模型 ID；不填写完整 `/v1/systemone` 路径、密钥、查询参数或 fragment |
| 决策强度 | `high` 或 `low` |
| 请求超时（毫秒） | 服务请求和连接测试的等待上限；输入前置处理另有总预算 |
| 密钥引用与 API Key | 专用引用名，如 `REFLEX_CUSTOM_API_KEY`，以及服务密钥；无认证服务无需密钥 |

API Key 留空会保留已存密钥。替换密钥须使用新的专用引用名；部署凭据为只读。密钥保存在 Host 凭据存储中，与普通设置和源码分开。切换自定义参数不会复制预置服务的凭据。

点击**测试连接与真实判断**，然后**保存**。测试使用当前草稿检查健康状态、模型可用性和固定判断，不会保存设置；编辑后需重新测试。保存后对新请求生效，正在执行的请求保留原配置。探测成功不等于任务完成或召回质量通过。

## 检查能力是否启用

产品 profile 加载输入判断与 Skill 选择。配置服务后，Reflex 记录真实判断，主模型随后继续执行；缺少配置或前置处理失败时，普通模型执行仍可继续。高级入口路由、Goal 纠偏和会话上下文恢复需要各自配置。**刷新能力状态**读取模块与配置状态；实际执行结果见会话记录。

**Continuum 无限记忆**开关也在 Reflex 配置页，默认关闭。它独立于 System3 的会话上下文恢复。开启任一功能都不能证明完整召回或任务验收通过。范围及远程数据配置参见[公共服务接入指南](../dev-continuum-reflex-integration/public-provider-configuration.zh.md)、[System3 配置参考](../../packages/experimental/system3/README.zh.md)和 [Continuum 指南](../../packages/context/continuum/README.zh.md)。
