# 语义监督模型验收

[English](supervision-semantic-validation.md) | 中文

四个隔离判断使用真实 `APUS-OpenJev-v1-9B-5949` 模型、high effort 和未修改的 0.8 采纳阈值，请求由生产监督及反馈定义生成。检查验证模型判断与确定性采纳条件，不能替代真实 Codex 任务、建议消费、正常终态和独立产物验收。

[初始英文相关性问题](supervision-semantic-initial.json)对无关营销窗口给出 0.62156 的无关概率，低于阈值。虽然独立动作问题偏好回正，Host 准入拒绝了纠偏。该正例失败保留记录。最终中文相关性问题明确对照整个充分的原生动作及路径窗口、Goal 和已接受要求，不要求隐藏上下文，也不把单项无关操作当持续偏离。

[最终响应](supervision-semantic-final.json)以 0.99566 的概率将不同的成功营销改动判为与财务目标无关，以 0.99559 的概率将财务相关工作判为相关。缺少路径的证据仍产生模型回正建议（0.85152），但 Host 因语义准入与重复工作证据均不足而拒绝。对于无关的成功验证，相关验证概率为 0.000335，未采纳改善结论。报告分开记录原始决策与 Host 结果，包括直接调用决策定义时的预期不符，避免将模型建议误报成已执行纠偏。

[首次真实 Codex 语义试验](semantic-codex-attempt1-interrupted.json)因 Host 整合构建的 readonly 转 JSON 类型错误而被外部停止。原生进程已终止并完成清理；报告明确记录 `error` 与外部中止原因。这次部分运行不算完整端到端验收，与仅模型判断的检查分开保留。
