# C-06 paired cache acceptance

English | [中文](cache-benchmark-design.zh.md)

## Scope and matrix

The prepared executor uses the shipped SDK profile and built CLI, the deployed pi-ai OpenAI-compatible DeepSeek adapter, and the real Reflex provider. It does not replace model answers. Two counterbalanced pairs run off/on then on/off, each in a fresh workspace and Session with identical six-file content, user prompts, model `deepseek-flash`, effort `low`, 8192 output-token limit and tool definitions. Each Session runs finance, a warm finance continuation, and an archived-trip recovery through three separate CLI processes: the second and third receive the same durable Session ID, making the third turn a real process-restart recovery. The 2026-10-10 run completed; each CLI process had a 120-second budget and Reflex context judgement used the deployed 15000 ms deadline. There was no retry, and every failure stays in the report.

“First-observed” is a fresh Session, not a verified cold provider cache: the provider exposes no cache flush or isolation guarantee. Fixed common prompt prefixes can already be cached or cross-warmed. Counterbalancing reduces order bias but two pairs are descriptive, not a statistical confidence claim. Warm continuation deliberately reuses the same task history. A physical restart is not assumed to clear the provider cache. Anthropic and OpenAI routes are outside this paid run; current credentials and a comparable configured route must be verified before expanding coverage.

## Measurements and acceptance

The observer hashes every exact canonical message at each real generation dispatch, every raw provider usage event, time to first text/tool delta, complete stream duration and errors. The SDK records complete task duration, output and persisted events. Reflex judgement receipts retain exact requests/responses, decision elapsed time and any reported provider usage; missing usage is unknown, never zero. The report retains all of them for independent accounting, including model requests caused by unexpected tools. Prefix comparison includes recoverable continuation and durable append; a difference is a failure to investigate, never normalized away. This observes Harness message identity, not a claim of byte-identical provider wire serialization across different adapters.

Executable assertions require independently computed Decimal total 1137.41, warm-continuation order A balance 835.12, preserved input hashes, all four restored facts, and unchanged complete prior-request message hashes. Before archived-trip recovery, the executor captures every Session JSONL byte prefix and checks its SHA-256 after the append; append is allowed, rewriting is rejected. Inspect projections to confirm that only unsubmitted tail text changes and frozen recovery appends. If no eligible fragment is actually removed, report the condition as no treatment, not a successful optimization. Match deployment context settings: deadline 15000 ms, request 4000 characters, fragment 1024 characters, 16 candidates, `protectRecentMessages=4`, threshold 0.9, recovery 8192 characters and 8 search results. Reflex effort remains its configured high default; generation uses deployed low effort. On/off differ only in context review mode; both expose the memory tool and cache anchor behavior. This isolates semantic projection cost rather than removing the whole feature/schema from baseline.

Compare absolute uncached input, cache-read, cache-write, output and Reflex usage per request and whole task, plus first-output and complete task duration. Use the persisted assistant usage as final request accounting; raw usage events remain available to check adapter translation and partial updates. Report cache-read share only when the provider’s disjoint counts are complete. Unknown prices prohibit currency savings. Neither a smaller heuristic prompt nor a positive cache-read count establishes net savings; retain adverse pairs and report any added Reflex latency. Route switching, pressure compaction and other adapters remain separate acceptance gaps.

## Running and artifacts

`cache-benchmark/run.py` defaults to printing the fixed plan without loading the SDK or calling a provider. Execution requires `--execute`, an existing built CLI, an unused output directory, and a root-coordinated exclusive provider window. Load credentials into the parent environment without printing them. The executor uses a unique temporary workspace. Each turn runs in a separate built headless CLI process; the second and third explicitly pass the same Session ID, so the third turn is a real process-restart recovery. Workspace and Session logs remain available for audit. The runner neither builds nor installs dependencies.

```sh
uv run --project python/sdk python docs/feat-reflex-control/cache-benchmark/run.py --exe apps/cli/lib/bin.js --output /private/tmp/reflex-cache-c06 --endpoint https://jev.example.invalid
```

Add `--execute` only in the assigned run window. `report.json` follows [the evidence schema](cache-benchmark/report.schema.json); per-condition `*.requests.jsonl` preserves canonical input hashes and stream observations. All material is synthetic; credentials and request authorization headers are never recorded. Shareable events replace reasoning/thinking blocks and fields with hashes, and request traces contain hashes rather than raw messages. Raw Session logs remain only in the private temporary workspace, outside committed evidence. The executor saves partial reports after each condition; process-level interruptions may leave the current trace and durable Session logs without a completed report row. Four keyless negative-control checks cover a wrong order A balance, a missing restored fact, reasoning redaction and changed original log bytes. Syntax, Ruff and plan checks also pass. The real evidence is recorded in [the C-06 report](evidence/cache-c06-real.md); all assertions for all four conditions passed. Currency cost is unknown; the four conditions recorded 16 generation requests plus bounded Reflex decisions, with extra model-chosen calls recorded rather than hidden.
