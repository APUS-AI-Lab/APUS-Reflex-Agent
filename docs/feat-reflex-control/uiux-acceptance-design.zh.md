# UI/UX 验收设计

[English](uiux-acceptance-design.md) | 中文

## 目标与授权

用户要求完整 UI/UX 验收。已批准范围包括修正共享设置布局与不准确的 Reflex 送达状态，保留已批准页面设计及运行时 API。真实 server13 检查发现 375px 视口的 Reflex 输入框仅宽 59px；固定导航栏也挤压通用设置。

## 布局与状态

视口不超过 640px 时，设置使用位于内容上方、占满宽度的横向导航。导航横向滚动，表单内容纵向滚动，标题、操作与关闭按钮保持可达。较宽布局保留现有分栏、设计变量与弹窗焦点行为。640×450 CSS 视口仅模拟 1280×900 窗口在 200% 下的重排；浏览器或 Electron 原生缩放仍是独立验收项。

监督 `unknown` 事件表示无法确认送达回执，文案不能误称 Reflex 未作判断。正在发送、已送达、效果已验证与原生恢复保持独立状态。不修改 API、持久化格式或模型路由。

配置与密钥组合保存采用带版本检查的补偿，不是跨服务事务。密钥写入被拒绝或回执无法确认时，仅在本次写入的准确配置版本仍有效时恢复本轮字段，并保留草稿供重试。存在并发配置变更或补偿失败时，保留较新配置并明确提示部分保存。密钥引用在点击保存时捕获，秘密不进入配置补丁。密钥回执丢失不能证明凭据存储未改变；即使配置已恢复，页面仍提示保存未确认。密钥写入已确认成功后，状态刷新失败不会改报保存失败。

## 验收

使用独立 browse 状态连接真实服务。检查首次入口、无效且未保存的草稿、保存与检测禁用、Escape 与焦点返回、键盘遍历、375/768/1280px 的明暗主题及 200% 重排。截图后目视检查。真实原生测试期间不提交模型请求、不保存 provider 配置。由 root 统一构建 Client 并重启服务，在实际构建界面复验受影响流程；源码回归不能替代该复验。检查结束后恢复原主题。

Client12/Web12 的[实际界面复验](evidence/uiux/after.json)已通过 375/768/1280px 明暗布局、键盘焦点围栏、Escape 焦点返回、无效草稿描述和持久化上下文恢复提示。375px 下输入框宽度从 59px 增至 271px；[此前失败](evidence/uiux/before.json)仍保留。640×450 仅验证重排；原生 Electron 200% 缩放与桌面安装包检查仍独立验收。本轮未提交模型请求、provider 保存或连接测试。
