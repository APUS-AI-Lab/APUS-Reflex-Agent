# 公开文档与证据审阅

[English](open-source-docs-audit.md) | 中文

## 范围

初始受跟踪清单覆盖 `docs/` 和 `tasks/` 下 749 个文本文件：542 个 Markdown、43 个 HTML、158 个 JSON、1 个 Session JSONL 和 5 个日志；另有 72 张 PNG／JPEG 图片及 6 个 PDF／PPTX／ZIP 附件。README、配置和源码还属于受跟踪文件秘密扫描的范围。这是审阅清单，不代表每个产物都获准公开。

## 发布原则

保留架构、API 文档、可复现的合成 fixture、来源引用和限定范围的验收摘要。排除真实运行对话、私有部署配置、私有源码清单和管理层内部演示稿。原始证据携校验和私有留存；公开摘要必须说明省略了原始内容。

- 归档八件内部管理材料：两份演示稿、三份 PDF、两张预览图和管理层 HTML。合成 demo ZIP 的八个成员经审阅后保留。

- 修正 README 和案例集：保留原文不保证无损召回；无 Jev 兼容不启用 Continuum；来源标记本身不证明能抵御召回文本中的恶意指令。

- 受跟踪文件 Gitleaks 已扫描 124.24 MB，无命中；Frontend 历史 424 个提交扫描通过。Harness 历史扫描覆盖 12,223 个提交／320.52 MB，返回 470 个模式命中：455 个配对摘要、2 个文档摘要、9 个合成凭据 fixture、2 个普通文字、1 个环境变量名和 1 个存储标识。审阅未识别出真实凭据；这是非零扫描结果的分类审阅，不是扫描器零命中退出。最终变更文件扫描、文档检查和独立差异审阅仍待完成。
- 公开前处理旧提交、分支、标签及发布附件中移出文件的历史副本。删除 HEAD 文件不会删除历史内容。
- 单独验证 Frontend 固定的 Runtime 及发布包。文档清理不会自动完成 provider、平台或签名验收。

## 仓库所有权

目标组织为 APUS AI Lab，两仓保持独立。所有权迁移与公开可见性是两件事。历史资料和发布说明处理方案审阅完成前保持私有；不静默改写共享历史，不把未运行的 CI 任务描述成通过。
