02 · 核心叙事：从 Context Window 到 Continuity Layer

普通 AI 记忆

保存聊天、生成摘要、做相似度召回。它回答“过去出现过什么”。

APUS Continuum

记录任务事实、纠正、权限和版本，由 Reflex 判断当前需要恢复什么。它回答“现在什么仍然有效”。

一句话传播

让 AI 从昨天的工作继续今天的任务。

这比“我们有更大的上下文”更容易形成长期产品认知。

不是把所有记忆都塞给模型，而是让 Reflex 决定此刻什么值得被想起。

04 · 最强 Demo：周五改到周一

90 秒视频脚本

  1. 输入：“迁移安排在周五。”
  2. 输入：“纠正，改到下周一。”
  3. 关闭 Agent，重新打开。
  4. 问：“继续迁移任务。”
  5. 展示 Reflex 选择、来源事件、旧版本 supersedes 关系。

镜头必须出现的 5 个信号

✓ 旧事实没有被物理删除

✓ 新事实成为当前有效版本

✓ 私有 scope 没有被注入

✓ 重启后 record ID 一致

✓ 模型可见输入可从 Session 重放

07 · 对外表达的边界

推荐说法

“可持续任务记忆”

“来源可追溯的 Agent memory”

“在有限窗口内维持任务连续性”

“Reflex-governed memory”

避免说法

“真正无限记忆”

“永不遗忘”

“零幻觉记忆”

“自动记住一切”

APUS Continuum 不承诺 AI 记住一切；它承诺记忆有事实来源，召回有决策，注入有边界，结果可回放。
