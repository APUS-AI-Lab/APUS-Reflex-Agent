Linux 桌面默认工作区验收

目标：以真实 Ubuntu 24.04 桌面用户目录配置复验v0.1.3 Full/Lite DEB。产品 tag、二进制、沙箱规则不变。

CI 安装 xdg-user-dirs → 独立 HOME / XDG_CONFIG_HOME → 系统 xdg-user-dir 解析 Documents → 安装原 DEB → 默认工作区 + 可编辑输入 → 保存标记 → 重启保留 → 卸载

变更：product-release.yml 在构建与重新验收任务安装系统目录工具；product-linux-smoke.mjs 配置隔离桌面目录、保留工具可达并检查默认工作区与重启持久化；product-linux-smoke.test.mjs 覆盖环境配置、错误解析与实际系统工具。

接口：prepareDesktopDocuments(env, query) 返回已由系统工具解析的 Documents；verifyDefaultWorkspace(page, directory) 要求默认选择和可编辑输入，目录必须实际存在。模型请求和用户私有凭据不进入验收。

验证：Node 语法检查、Linux/Mac/重新验收辅助脚本定向测试；Linux 实际 xdg 工具测试；通过 unix_requalification 对 原构建记录及 v0.1.3 tag 的两版原始安装包重新验收。
