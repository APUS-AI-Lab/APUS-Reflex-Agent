# xDAN System3 Frontend

本仓库是 dataelement/dsh-desktop 的独立私有副本，供 System3 桌面体验设计与后续集成使用。应用源码与品牌当前沿用上游，仓库名称不表示已经完成 System3 后端接入。

- GitHub： https://github.com/cryptoSUN2049/xDAN-System3-Frontend
- 上游： https://github.com/dataelement/dsh-desktop
- `origin`：私有仓库；`upstream`：上游项目。
- MIT 许可证与 DataElement 版权继续保留于根 LICENSE。

桌面负责窗口、目录、启动恢复与原生 Conversation 的产品呈现；xDAN-System3-Harness 负责入口与过程决策、执行、权限、任务生命周期及真实事件。后续 UI 设计贯通入口智能、过程智能、体感智能，不另建第二套执行核心或前端任务数据库。

初始复制保留主分支提交历史；上游两个 Python 发布说明脚本仅作 Ruff 格式化，语法树一致。未安装依赖、启动应用或验证安装包；本次不宣称桌面功能通过。
