APUS Reflex 桌面运行时集成

桌面客户端由一体化仓库中的 frontend/ 管理，与 Harness 从同一份源码组装。客户端复用原生 Session、工具执行和权限机制。

加载关系

Desktop main → runtime-manifest → dsh 入口 → Host / Session → Web UI
安装包：resources/system3-runtime 包含已部署的运行时及依赖，拒绝使用源码目录。
Reflex UI 展示已记录的决策；可选远端服务仍需明确配置与授权。

配置与验证

连接 Reflex 服务不会自动开启路由、监督或 Continuum。安装包、模型请求与持久记忆分别验收；本页不代表这些验收已经完成。

参阅运行时打包说明、模型配置教程和发行流程。
